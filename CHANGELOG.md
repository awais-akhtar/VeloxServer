# Changelog

## 0.1.0

- Initial public release of VeloxServer.
- Added static serving, reverse proxying, stream proxy naming, TLS controls, metrics, structured logs, caching, plugin hooks, auth, AI model routes, and AI-assisted deployment repair.
- Added `veloxserver validate` and `veloxserver doctor` for configuration and runtime readiness checks.
- Added deployment examples, production hardening notes, packaging metadata, CI, wheel builds, and PyPI Trusted Publishing workflow.
